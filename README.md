# موقع مهيب

موقع مهيب يعمل الآن كنسخة ديناميكية مع لوحة تحكم وقاعدة بيانات SQLite.

للنشر على الإنترنت، النسخة مجهزة أيضًا للعمل مع Supabase بدل SQLite. راجع:

```text
DEPLOYMENT.md
```

## التشغيل المحلي

```bash
cd "/Users/mohammedaldemerdash/Downloads/موقع مهيب"
python3 server.py 4174
```

الموقع:

```text
http://127.0.0.1:4174/
```

لوحة التحكم:

```text
http://127.0.0.1:4174/admin.html
```

بيانات الدخول الافتراضية عند أول تشغيل:

```text
اسم المستخدم: admin
كلمة المرور: Muheeb@2026
```

بعد أول دخول، غيّر كلمة المرور من لوحة التحكم عبر قسم `الأمان`.

يمكن تغييرها قبل أول تشغيل عبر متغيرات البيئة:

```bash
MUHEEB_ADMIN_USER="admin" MUHEEB_ADMIN_PASSWORD="StrongPasswordHere" python3 server.py 4174
```

## أين تحفظ البيانات؟

- طلبات العملاء والفعاليات تحفظ في `data/muheeb.sqlite3`.
- صور الفعاليات المرفوعة تحفظ في `uploads/events/`.

في نسخة النشر:

- طلبات العملاء والفعاليات تحفظ في Supabase Postgres.
- صور الفعاليات تحفظ في Supabase Storage داخل bucket باسم `event-images`.

## ماذا تدير لوحة التحكم؟

- استقبال طلبات العملاء القادمة من نموذج الموقع.
- تغيير حالة الطلب وكتابة ملاحظات متابعة.
- تعديل نصوص الموقع الأساسية من قسم `محتوى الموقع`.
- تعديل واستبدال وإظهار أو إخفاء صور الموقع من قسم `صور الموقع`.
- إضافة وإظهار أو إخفاء اختيارات خانة `مجال الاهتمام` من قسم `اختيارات النموذج`.
- إضافة وتعديل وحذف الفعاليات.
- رفع صورة غلاف وصور إضافية للفعالية.
- نشر أو إخفاء الفعالية من الموقع.
- إدارة المستخدمين والصلاحيات وملاحظات المتابعة المسندة.

## ملفات النشر المهمة

- `supabase/schema.sql`: إنشاء الجداول والصلاحيات والتخزين في Supabase.
- `supabase/cms_upgrade.sql`: جداول إدارة محتوى الموقع وصوره واختيارات النموذج.
- `supabase/team_permissions_upgrade.sql`: جداول المستخدمين التفصيلية، صلاحيات اللوحة، ملاحظات الطلبات المسندة، والإشعارات.
- `supabase/workflow_profile_events_upgrade.sql`: صلاحيات الطلبات المتقدمة، قراءة الإشعارات، استفسارات الملاحظات، طلبات تعديل بيانات المستخدم، وتفاصيل الفعاليات الموسعة.
- `supabase/notifications_inquiries_media_upgrade.sql`: تفعيل ردود الاستفسارات، ضبط ظهور الإشعارات للمستخدم المعني فقط، وإضافة صور خلفية دخول المشرف والفوتر.
- `supabase-config.js`: تضع فيه رابط Supabase و`anon public key`.
- `supabase-client.js`: طبقة الاتصال التي تعمل مع Supabase عند النشر أو مع `server.py` محليًا.
- `vercel.json`: إعدادات نشر الواجهة على Vercel.
- `.gitignore`: يمنع رفع قاعدة البيانات المحلية والملفات الثقيلة.
